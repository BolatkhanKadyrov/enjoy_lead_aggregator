# Enjoy · документы цеха

Telegram-бот принимает одну полную выгрузку чеков в формате XLSX и возвращает в личный чат два PDF для печати на A4. Первый содержит план кухни и отчёт по выгрузке. Второй содержит накладные для точек. Расчёт выполняется локально по значениям Excel. Ключ внешней ИИ-службы не требуется.

## Запуск на Railway

1. В новом проекте Railway выберите **Deploy from GitHub repo** и этот репозиторий. Для сервиса достаточно одного экземпляра. Dockerfile устанавливает Python и шрифты для кириллицы и знака ₸.
2. Подключите **Volume** к сервису, например по пути `/data`. Здесь хранятся база SQLite, справочники, последняя выгрузка каждого пользователя и незавершённые диалоги.
3. В **Settings → Networking** создайте публичный домен. Бот возьмёт адрес Mini App из `RAILWAY_PUBLIC_DOMAIN`. Для собственного домена задайте `PUBLIC_URL=https://ваш-домен`. Приложение открывается по корневому адресу.
4. В **Variables** добавьте `BOT_TOKEN` из BotFather и `ADMIN_IDS` со списком числовых ID личных Telegram-чатов администраторов через запятую.
5. Для первого запуска откройте приватный файл `enjoy-catalog.json` в текстовом редакторе и скопируйте весь текст вместе с фигурными скобками (**Ctrl+A**, затем **Ctrl+C**). В **Variables → New Variable** введите имя `INITIAL_CATALOG_JSON`, вставьте скопированный текст в **Value** и сохраните переменную. Также можно загрузить файл в корень подключённого Volume под тем же именем. Меню, адреса и исключения импортируются один раз. После успешного запуска переменную можно удалить.
6. Примените изменения и дождитесь успешной проверки `/health`. Откройте бота в личном чате и отправьте `/start`. Администратору доступна кнопка **Настройки цеха**. Дополнительная настройка меню в BotFather для этой кнопки не требуется.

Бот получает обновления через long polling. Используйте один запущенный процесс на токен и отдельного бота для тестового окружения. Railway передаёт приложению `PORT` автоматически. Резервные копии базы можно делать средствами Railway Volume.

[Постоянный том Railway](https://docs.railway.com/volumes) · [Публичный домен Railway](https://docs.railway.com/networking/public-networking)

## Работа в Telegram

- Отправьте XLSX как документ в личный чат. Приём по будням, с 18:00 до 23:30 включительно по времени Астаны. Бот проверяет время отправки сообщения. Дата закрытия чека и имя файла не влияют на дату заказа.
- На кухонном листе указываются день сбора и следующий рабочий день доставки. Пятничный заказ оформляется на понедельник. Рабочими считаются понедельник — пятница.
- Если встретилось новое блюдо, выберите раздел кнопкой или введите название. Регистр букв не влияет на совпадение. Новый раздел создаётся сразу. Для новой точки укажите адрес или нажмите **Пропустить**. Ответ запоминается для последующих выгрузок.
- Чтобы исправить заказ, отправьте всю таблицу заново. Новый принятый файл заменяет предыдущий только в вашем чате. Неверный файл или отправка вне интервала сохраняют прежнюю выгрузку. Команда `/resume` возвращает к текущему вопросу или повторно формирует документы по последней принятой таблице.

### Печатные документы

В план входят все порции, включая обмен и заказы точек без накладных. Служебные префиксы вида `a)` удаляются. Кухня видит одну строку с общим количеством каждого блюда в его разделе.

Каждый исходный чек получает свою накладную с исходным номером. Маленькие накладные занимают половину листа, крупные целый лист. У многостраничного чека повторяются номер и заголовки. Обмен показывается отдельно и учитывается в отгруженном количестве. Итог к оплате берётся из столбца «Оплачено». Поле для курьера заполняется от руки.

В отчёте указаны число чеков и накладных, исключённые точки, количество порций и расхождения по чекам. Расхождение равно значению «Оплачено» за вычетом суммы итоговых цен товарных строк. Денежные расчёты используют десятичную арифметику.

### Mini App

Откройте **Настройки цеха** через `/start` или `/admin`. В разделе «Точки» редактируются адреса и участие в накладных, в разделе «Блюда» создаются разделы и меняется распределение блюд. В разделе «Приём файлов» настраивается время начала и окончания приёма. API проверяет подпись Telegram и ID администратора на каждом запросе. [Проверка данных Telegram Mini App](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app)

## Локальная разработка

Требуются Python 3.12 и шрифты DejaVu Sans (в контейнере устанавливаются автоматически; в Windows используются системные шрифты). Для запуска в PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:BOT_TOKEN = '<токен тестового бота>'
$env:ADMIN_IDS = '<ваш числовой ID>'
$env:PUBLIC_URL = 'https://<публичный HTTPS-адрес сервиса>'
$env:INITIAL_CATALOG_JSON = Get-Content -Raw -Encoding utf8 'путь\к\enjoy-catalog.json'
.\.venv\Scripts\python.exe main.py
```

По умолчанию HTTP-сервер слушает порт 8080, база находится в `data/`. На Linux команды выполняются через `.venv/bin/python`. Для тестов токен и рабочий справочник не нужны:

```sh
python -m pip install -r requirements.txt pypdf
python -m unittest discover -s tests -v
```
